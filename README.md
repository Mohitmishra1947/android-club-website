# Android Club Website

A responsive website for **Android Club, VIT Bhopal University**, built using HTML, CSS, and JavaScript.

## About the Project

The website introduces Android Club and its activities, providing visitors with information about the club, projects, events, and community.

## Features

- Responsive desktop and mobile layout
- Modern green and black theme
- Mobile navigation menu
- Projects and events sections
- About Us section
- Contact information and social media links
- Smooth scrolling and interactive buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Inter and Space Grotesk)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/android-club-website.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the project

```bash
cd android-club-website
```

### 3. Run the website

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a local development server.

## Customization

- Edit `index.html` to change website content and structure.
- Edit `styles.css` to modify colors, layouts, and design.
- Edit `script.js` to update interactive features.
- Place website images and other assets inside the `assets` folder.
